# 尺寸對照表（首頁「輸入身形，找合身的睡衣」）

首頁的尺寸推薦不靠模型，而是拿顧客輸入的身高、體重、胸圍（選填），去比對每件睡衣、每個尺寸的「適穿範圍」。
這張範圍表就是**尺寸對照表**，存在資料庫的 `product_fits` 表（見 `prisma/schema.prisma` 的 `ProductFit`）。

## 平常怎麼維護：後台「尺寸對照表」

後台左側選單 →「尺寸對照表」（`/admin/fit-chart`，只有管理員進得去）。

1. **下載**目前的商品清單（.xlsx）。每件上架商品、每個尺寸一列，已經填過的範圍會帶好。
2. 在 Excel／Google 試算表填範圍。
3. **上傳** → 預覽 → 確認寫入。

### 下載檔的欄位

| 欄位 | 說明 |
|---|---|
| 商品代號 | 灰底，**不要改**。官網商品網址最後一段（slug），用來對應商品 |
| 商品名稱（參考） | 灰底，方便辨認，改了也不會匯入 |
| 品牌（參考） | 同上 |
| 尺寸 | 灰底，**不要改**。從規格名稱認出來的 S／M／L…；認不出尺寸的商品是 `FREE`（單一尺寸） |
| 有現貨（參考） | 這個尺寸目前有沒有現貨。沒現貨的尺寸首頁不會推薦，但資料可以先填 |
| 身高下限／上限(cm) | 整數、含邊界。留白＝那一端不設限 |
| 體重下限／上限(kg) | 同上 |
| 胸圍下限／上限(cm) | 穿的人的胸圍（量胸部最高點一圈），不是衣服的胸寬 |
| 備註 | 只給後台看 |

第一列（表頭）凍結；檔案裡另有一張「填寫說明」工作表。

### 上傳的規則

- 收 `.xlsx`（讀第一張工作表）或 `.csv`／Tab 分隔，最大 2MB。
- **檔案裡出現的商品**：適穿資料整份換成檔案內容。範圍全部空白的尺寸＝沒有資料（原本有的會刪掉）。
- **檔案裡沒出現的商品**：不動。所以不想改的商品可以整列刪掉，也可以分批上傳。
- **任何一列有錯就整份不寫**。預覽會列出「第幾列、哪一欄、為什麼」。
- 預覽列出會新增、修改、刪除幾個尺寸與明細，按「確認寫入」才寫。
  確認時伺服器會重新解析同一個檔案再比對一次；預覽之後資料被別人改過，會要求重新預覽。
- 每次寫入都記在稽核紀錄（`AuditLog`，action = `fit-chart.import`）。
- 寫入後首頁會重新產生；至少一件上架商品有資料時，首頁才會出現尺寸推薦那一區與 Hero 第一張的按鈕。

## 命令列（本機開發用）

```bash
npx tsx scripts/import-fit-chart.ts <對照表.xlsx|.csv> --dry-run
```

拿掉 `--dry-run` 就寫入 `DATABASE_URL` 指向的資料庫。與後台共用同一套解析、驗證、寫入（`src/lib/fit-chart/`）。
正式站請用後台，不需要再把腳本送上主機。

## 比對與排序（`src/lib/recommend/fit.ts`）

1. 只看有現貨的尺寸。
2. 每個尺寸逐項比對身高、體重、胸圍：在範圍內＝符合；低於下限／高於上限＝不符合。顧客沒填或那一列沒給範圍的項目不算分。
3. 每件商品挑最合適的尺寸：不符合項目少 → 符合項目多 → 超出幅度小 → 越接近範圍中間。
4. 全部符合的排前面（越接近範圍中間越前），部分符合的排後面並標出哪一項不符；一項都不符合的不推薦。最多 6 件。
