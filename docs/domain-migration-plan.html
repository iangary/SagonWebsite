換網域到 www.sagan.com.tw

莎岡選品店 · 流程、時程，以及哪些現在就能先做 · 2026-11-09

先講最重要的發現：sagan.com.tw 現在就是莎岡選品店的「舊站」 查了一下，www.sagan.com.tw 目前開出來是開店平台上的莎岡選品店，裡面有 73 個商品、8 個分類，DNS 由 Cloudflare 管理，而且沒有設定收信（沒有 MX 記錄，所以搬過來不會影響任何信箱）。

所以這次不只是換網址，而是「新站接手舊站的網址」：

  • ✅ 不用註冊網域，也不用等 TWNIC 審核：DNS 在 Cloudflare，改完大約 5 分鐘就生效。
  • ⚠️ DNS 一改，舊站就下線：舊平台上的會員、進行中的訂單、Google 上的舊商品連結都要先想好怎麼處理。
  • ✅ 可以回退：舊平台還沒停約之前，把 DNS 改回去，舊站 5 分鐘內就會回來。

① 現在就能先做（不影響任何正在跑的網站）

準備階段

新站、舊站照常營業，這些可以並行
1. 把 Cloudflare 目前的 DNS 設定截圖存起來
你5 分零風險
這就是回退的依據。另外看一下 Cloudflare 的「Rules → Redirect Rules／Page Rules」有沒有設定，目前 sagan.com.tw 會 302 導到 www，可能就是那邊設的。切換之後要關掉，免得跟新站自己的導向打架。
2. 先備好新站的設定檔（Caddyfile、環境變數）
我30～60 分只改本機
主網址設成 www.sagan.com.tw；sagan.com.tw、chenkuanyi.com.tw、www.chenkuanyi.com.tw 一律 301 導過去。APP_URL／AUTH_URL 都改成 https://www.sagan.com.tw。改好先放著，切換當天才上傳。
附帶一件事：主機上的 /srv/sagon/.env（裡面有 SITE_DOMAIN）在本機沒有正本，要先從主機拉回來，才能照 CLAUDE.md 的規矩改。
3. 做舊網址 → 新網址的 301 對照表
我做草稿 1～2 小時你核對 30 分零風險
舊站的商品網址長這樣：/product/detail/2432120，分類是 /category/187774，新站對不上，切過去會全部 404，Google 排名和別人分享的連結都會斷掉。我從舊站的 sitemap 把 73 個商品、8 個分類對應到新站的 slug，對不到的你再幫我指定。/about、/faq、/contact 新站剛好也有，不用另外處理。
4. Google、LINE 登入後台加上新網址
你15 分新舊可並存
兩邊都允許填多個 redirect URI，現在先加上（舊的先別刪）：
https://www.sagan.com.tw/api/auth/callback/google
https://www.sagan.com.tw/api/auth/callback/line
Google 那邊的「已授權的 JavaScript 來源」也加上 https://www.sagan.com.tw。
5. 寄信網域：在 Resend 加入 mail.sagan.com.tw
你20 分 + 等驗證零風險
在 Resend 新增網域，把它給的 DKIM、SPF 記錄加到 Cloudflare，再自己加一筆 DMARC（_dmarc.mail.sagan.com.tw，先設 p=none）。在驗證通過之前，繼續用現在的 mail.chenkuanyi.com.tw 寄信，所以這件事不用跟切換綁在同一天。
6. Google Search Console 驗證 sagan.com.tw
你10 分零風險
用 DNS TXT 記錄做「網域資源」驗證。舊站可能已經驗證過了，可以先看一下；驗證過的話，切換後就能直接看到 404 和排名的變化。
7. 決定舊平台的會員、訂單、合約怎麼處理
你決定看資料量最大的變數
見下方「需要你決定的事」第 1 點。這件事決定了第 ① 階段要花 2 天還是 2 週。
8. 確認新站的上線清單都做完了
我列你補看剩幾項
換到 sagan.com.tw 之後，客人就是真的會來下單了。docs/deploy.md §7.7 那張表（綠界正式金鑰、SMTP、三竹簡訊、清掉測試優惠券、換掉爬蟲來的商品素材……）要在切換前全部打勾。

② 切換當天（約 1 小時，挑離峰時段）

切換

建議平日早上或深夜；照順序做
1. 舊站掛公告或暫停接單
你5 分
避免有人在切換那幾分鐘內，到舊站下單付款。
2. 上傳新的設定檔並重啟網站
我5 分
照 CLAUDE.md 的送檔流程：主機先備份 .bak-MMDD-HHMM，再 scp、chmod 600、--force-recreate web。這時候 chenkuanyi.com.tw 還會照常運作。
3. Cloudflare 改 DNS
你5 分舊站從這裡開始下線
sagan.com.tw 和 www 都改成 A 記錄，指向 103.1.221.67，雲朵要點成灰色（DNS only），不然憑證簽不到。www 原本是 CNAME 指到 CloudFront，要先刪掉再新增 A 記錄。順便關掉第 ① 階段第 1 點找到的 Cloudflare 導向規則。
4. 等 DNS 生效，Caddy 自動簽 HTTPS 憑證
我盯著5～15 分
網站打不開的時間就在這一段。我會一直看 log，確認憑證簽下來。
5. 綠界後台的 callback 網址改成新網域
你10 分
漏掉的話，客人付了錢，訂單還是停在未付款，而且不會有任何錯誤訊息。黑貓後台如果有填網址，也要一起改。
6. 全面測一次
我跑 smoke.sh你下一筆真單20 分
要測：首頁、商品頁、舊網址有沒有正確 301、Google 登入、LINE 登入、下單付款、收到訂單通知信、chenkuanyi.com.tw 有沒有導到新站。
出事怎麼回退（5 分鐘內） Cloudflare 照第 ① 階段第 1 點的截圖改回原本的 DNS，舊站就會回來。主機上的設定檔用 .bak-MMDD-HHMM 還原，chenkuanyi.com.tw 就恢復原狀。所以舊平台的合約，請等新站穩定跑一陣子再停。
切換後必然會發生、但不算壞掉的事 新站的會員登入狀態是綁網域的，用 chenkuanyi.com.tw 登入的人會被登出，要重新登入一次。舊平台的會員帳號不會自動出現在新站，除非決定要搬（見下方第 1 點）。

需要你決定的事

  1. 舊平台的會員和訂單要不要搬到新站？ 這是整個時程最大的變數。不搬：舊會員到新站重新註冊，舊訂單留在舊平台查詢就好，最快 2～3 天可以切。要搬：要先看舊平台能匯出哪些欄位（密碼通常匯不出來，會員需要重設密碼），大概要多 3～7 天。另外，舊站上還沒出貨的訂單，要在舊平台處理完。
  2. 切換日期和時段 第 ① 階段的第 7、8 點完成之後就能切。建議選平日的離峰時段，而且你要在場，才能改 Cloudflare 和綠界後台、下測試單。
  3. Cloudflare 的橘色雲（CDN／代理）要不要開？ 切換當天一定要先關（灰色），讓憑證簽得下來。之後要開也可以，但 SSL 模式必須設成「Full (strict)」，不然會無限導向。不開也完全沒問題，比較單純。
  4. Shopee 串接 還在另一個分支開發中，裡面的 Redirect URL 和推播 callback 是寫 chenkuanyi.com.tw。要上線的話，到 Shopee 後台直接填 sagan.com.tw 就好，那份文件我到時候一起改。
